# Σ Alpha Ω — Sigma Alpha Omega Idle Experiment

### Version 0.2.0 | Windows | Experimental idle RPG

**Sigma Alpha Omega Idle Experiment** is a work-in-progress, deterministic, modular C++ idle RPG. It explores how much animated artwork, equipment, crafting, progression, and interactive UI can fit into a deliberately lightweight, cache-first Windows application.

The game is developed in Visual Studio and uses authored 1920×1080 PNG artwork, independent Math modules, Conductor groupings, and reusable caches. Instead of treating every object as something that must be rebuilt every frame, the architecture selects and combines previously prepared results.

## What's New in v0.2

- **Major Toth mathematics expansion:** Direct input for addition, subtraction, multiplication, division, powers, and roots, with numeric results and step-by-step mathematical explanations delivered through the Toth/Bastet interface.
- **Crafting screen:** Egyptian-inspired, jewel-encrusted tablet with animated scenery and separate Materials, Tools, Gear, and Buildings categories.
- **27 defined recipes:** 10 crafting materials, 3 Oak tools, 7 Fiber armor pieces, and 7 Oak armor pieces.
- **Crafting quantity and queues:** Choose the amount to craft. Each output completes individually, using numerical ingredient transactions rather than moving PNGs through the inventory.
- **Crafting progression:** Separate Materials, Tools, Gear, and Buildings mastery tracking contributes to overall Crafting, Application, Discipline, Practice, and character progression. Buildings recipes are reserved for a later update.
- **Scrollable recipe catalog:** Eight reusable recipe locations per page; scroll the mouse wheel to see more recipes. The other two crafted-item panels are reserved for recipe details and quantity/status.
- **More equipment:** Fiber and Oak armor artwork, Oak Axe equipment poses, and Oak Pick Axe / Oak Scythe crafting entries.
- **Equipment swapping:** Inventory and compatible gear slots use the existing equipment-ID selection and completed animation groupings.
- **Slower resource economy:** Harvesting provides one base Oak Log per completed tree and one base Grass and Straw per completed Tall Grass cycle, before existing progression-related bonuses.
- **No free starting gear:** New profiles receive **no automatically granted Stone Sickle or temporary Fiber/Oak test gear**. Equipment is obtained through gameplay rather than preloaded test gifts.

## Gameplay

### Harvesting

Collect Grass and Straw from Tall Grass or harvest Oak trees for Oak Logs. The character performs a continuous harvesting animation; numerical damage changes select cached visual stages. Harvesting supports its own incremental skills and contributions to character progression.

### Crafting

Start with the harvested resources **Grass, Straw, and Oak Logs** and process them into more advanced materials:

- Grass Fiber, Grass Cord, Grass Rope
- Oak Beam, Oak Planks, Oak Staves
- Straw Bundle, Straw Thatching
- Wooden Pegs, Woven Grass Mat

Use those processed materials to craft **Oak Axe, Oak Pick Axe, Oak Scythe**, and the **Fiber and Oak armor sets**. The Pick Axe and Scythe currently have crafting/inventory entries; their independent equipment-pose integration is not established in this release source. The Oak Axe has registered animated equipment artwork.

Recipes have numerical ingredient costs, crafting times, and level requirements. Higher crafting mastery improves effective crafting speed **without changing the scene animation speed**.

### Toth / Bastet — Expanded Deterministic Mathematics

**Toth now does much more mathematics than in v0.1.** The mathematical system is built from separate C++ Math modules and Conductors that prepare reusable mathematical relationships, process an entered expression, and forward a completed result to the existing Toth/Bastet interface.

The v0.2 source includes support for:

- **Addition:** Including signed and decimal values, with digit-by-digit place-value explanations and carrying.
- **Subtraction:** Numerical subtraction with its own cached digit relationships and calculation steps.
- **Multiplication:** Digit-level multiplication, carrying, and worked steps.
- **Division:** Numerical division with calculated results and explanatory steps.
- **Powers:** Exponentiation through the Powers Math/Conductor modules.
- **Roots:** Square roots and supported higher-degree roots through the Roots Math/Conductor modules.

Try entering an expression directly into Toth's input area and submitting it:

```text
12.5+7.25
27-9
12*8
144/12
3^4
sqrt(81)
root(3,27)
```

Expressions are routed by their operation to the appropriate Math/Conductor path. The **answer is displayed in Toth**, and **Bastet can display the explanation steps** generated by the mathematical conductor. This is a local, deterministic, cache-first mathematics system—not a remote calculator or a generic AI text response. Inputs and precision are subject to the limits of the relevant operation; the above examples demonstrate the supported input forms rather than a claim of full symbolic algebra.

Toth also retains its command interface, cached alphabet-based text presentation, and connected language/definition capabilities. The longer-term D.I. learning, Research, Wisdom, and Intelligence integration remains planned rather than a completed v0.2 feature.

### Inventory and Equipment

- Inventory resource stacks up to **10,000**; equipment stacks of **1**.
- Drag items with the cursor to move them between valid locations.
- Equip compatible items in the Gear panel and swap existing equipment.
- Right-click an inventory stack to delete it.
- Item counts, equipped gear, and unlocks are saved with the player profile.

### Character Progression

Harvesting and crafting feed into incremental skills and character attributes rather than replacing one another. Toth provides progression feedback. The broader long-term design links the separate D.I. learning system with future Research, Wisdom, and Intelligence progression; that learning integration **is not part of this v0.2 release**.

## Installation / Playing the Release

1. Download the **v0.2 Release** package or repository contents.
2. Keep `Program.exe` together with the full `SAO_I_E Assets` folder. **Do not delete the transparent PNG assets or change their relative folder names.**
3. Run `Program.exe` on Windows. The first use of a math operation may generate its reusable `SAO_*_Table.txt` data file beside the executable, so run from a folder where the application can write files.
4. Create a new player profile for a clean v0.2 experience.

Typical release layout:

```text
Sigma-Alpha-Omega-Idle-v0.2/
├── Program.exe
├── SAO_I_E Assets/
│   ├── Main Screen/
│   ├── Crafting/
│   ├── Gear/
│   └── ... other required game asset folders ...
└── README.md
```

The game generates/reuses its internal cache files; generated caches and personal save files do not need to be included in the public release.

**Existing profiles:** Removing the automatic grant code does not erase previously saved equipment. To start without any earlier testing gifts, create a new profile or back up your existing `SAO_I_E Assets/Player Saves` directory before resetting its contents.

## Architecture and Efficiency

The core architecture is a forward-only chain:

```text
Math → Conductor → Converging Conductor → Cache Node
     → Shared Prime Cache Node → Program
```

- **Math nodes** load exact existing artwork and prepare cache representations.
- **Conductors** select and combine groupings through addition/subtraction.
- **Cache nodes** retain reusable results and forward completed outputs.
- **Program** receives completed presentation data; it is not a second animation or grouping controller.
- Numerical gameplay updates are kept separate from unnecessary image rebuilding.

**Observed memory usage:** The developer reports that the current Release build stays **below 30 MB RAM** during their testing. This is a measured observation from a particular system, **not a guarantee** across every computer, save, or future version. Earlier isolated animation benchmarks also demonstrated very low CPU use; actual performance varies by activity and machine.
